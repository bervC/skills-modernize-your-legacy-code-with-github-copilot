# COBOL Account Management System Test Plan

This plan describes the behavior implemented by the current COBOL application. Start a fresh application for cases that require the initial balance; the balance starts at `1000.00` and is held in memory only. Amounts and balances have two implied decimal places, but the program displays them without a decimal point (for example, `1000.00` is displayed as `00100000`).

Run each case interactively from the menu. “Actual Result” and “Status” are left for the tester to complete. The program does not define requirements for negative amounts or balance overflow; clarify those rules with stakeholders before treating them as acceptance criteria or implementing them in Node.js.
